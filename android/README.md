# 费曼物理 Android 版
当前发布版本：v3.3.0。学生端无需账号密码，可通过邀请码、摄像头二维码或二维码图片加入同一局域网内由 Windows 或 Android 教师设备托管的班级。

这是与 Windows 版并列的 3.3.0 独立 Android 外壳。它把项目根目录的网页、教材目录、题库、完整变式训练模块、离线二维码识别库、局域网班级主机和图标打包进 APK，并通过 `appassets.androidplatform.net` 的 HTTPS 本地资源入口在系统 WebView 中离线运行。包名、URL scheme、私有存储和备份标识保持兼容。

## 平台能力

- 最低 Android 6.0（API 23），目标 Android 16（API 36）
- IndexedDB 保存题库、视频、诊断、作答、复习和实验记录
- HTTPS 本地资源入口保证同源存储，并关闭 WebView 的任意文件访问
- 安卓文件选择器导入 JSON、选择本地视频、图片和文档
- 摄像头拍照扫描试题并离线识别二维码
- 原生 OCR 桥支持能力协商和结构化结果协议；当前依赖精简构建未捆绑离线 OCR 引擎，能力返回不可用后依次尝试浏览器 `TextDetector` 和人工录入，不伪造识别结果
- 经用户授权调用麦克风；按设备能力调用运动、环境光和磁传感器
- 相册、多文件、拖拽与剪贴板图片上传
- 安卓文件保存器导出完整 `.pslab`/轻量 JSON 备份和单个扫描附件
- HTTP/HTTPS 互联网题源、Bing 搜索及外部网页优先调用 Microsoft Edge，缺失 Edge 时使用手机当前的默认浏览器
- APK 使用项目专用 PKCS#12 证书签名
- 与 Windows 版共用 1900 道完整本地题：八年级 300 道、九年级 500 道、高一 300 道、高二 300 道、高三 500 道；另保留 2020—2025 年长沙中考及湖南适用高考物理 12 套、232 条题号与考点索引及原卷入口
- 包含 400 道“物理研习室原创·长沙模拟考结构适配专项”，九年级和高三各 200 道；这些题为应用内原创，并非长沙学校模拟卷原题，未复制第三方试卷题干、图像或答案
- 共用 3.3.0 学习闭环：学生档案、每日测试、前概念诊断、分步导师、五级提示、完整专项变式、多表征物理模型、透明校验、基于真实作答的间隔复习、学习报告、教师变式审核与分层作业预览
- 学生可在“我的”页面直接打开“加入老师班级”，填写备注名和邀请码，或实时扫描/选择教师二维码；不要求登录名和密码，加入流程只申请 `student` 权限。
- Android 会在应用运行期间托管持久化班级服务，并通过原生桥立即使用本机回环地址创建班级；分享二维码只携带其他设备可达的私有局域网地址。原生网络桥只允许访问 TCP 8788 上的回环或私有局域网地址，并通过 UDP 18788 发现同一网络中的 Windows/Android 班级主机；不会让包含原生桥的 WebView 打开任意远程网页。
- 教师可解析 DOCX、PDF、旧版 Word 与扫描图片；离线能力不足时可调用配置好的受控 ChatGPT 服务端，解析结果必须人工审核

## 已知边界

- WebView 是否提供环境光和磁传感器接口取决于设备与系统版本；界面会先检测再启用。
- 班级成员关系可与同一局域网的 Windows 或 Android 主机联机；教师设备必须保持应用运行。完整学习档案仍保存在本机，跨端学习数据通过 `.pslab` 或轻量 JSON 手动迁移。
- ChatGPT 功能需要部署并配置项目 `server` 目录中的受控服务端；APK 不包含 OpenAI API 密钥。
- 客户端会优先请求受控网关的 `/v1/physics/tutor-turn`；生成外部/拍入题的变式时使用 `/v1/physics/generate-variants`。网关不可用时导师退回本地五级提示，变式则仅使用可验证的本地题模或审核题族，不会伪造生成成功。
- 当前 `android.jar + javac` 构建没有离线 OCR 引擎/模型；原生桥会明确报告 `available: false`。浏览器提供 `TextDetector` 时可尝试本地识别，否则保留人工录入，所有结果都必须确认。
- 当前版本不把图片或草图自动解释为可靠的手写公式、受力图或电路语义。
- 自动判定覆盖可可靠提取的选项和数值；解释题及复杂步骤进入人工复核。

## 构建

运行 `tools/build_android.ps1`。版本与文件名从根目录 `version.json` 读取。脚本使用工作目录同级的 `.android-build-tools` 中的 OpenJDK 17、Android SDK Platform 36 和 Build Tools 36.0.0，不依赖 Gradle 或 Maven。

首次构建会在 `signing` 目录生成签名证书和随机密码配置。该目录决定后续版本能否覆盖升级，必须私下备份，不能随 APK 公开分发。

发布文件输出到项目根目录的 `发布/Android`，不会覆盖 Windows 安装程序。
