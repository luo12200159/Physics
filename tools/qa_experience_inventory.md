## 状态变化

- 未初始化 → 首次启动对话框 → 学生今日页。
- 今日 → 练习 / 错题 / 我的 → 返回今日。
- 今日推荐题 → 分步导师 → 提示 → 作答 → 迁移 → 复习。
- 拍题空白 → 图片/文字待确认 → 保存 → 立即订正。
- 学生 → 教师 → 家长 → 学生。
- 学生外链关闭 → 教师开启 → 学生显示带风险提示的外部检索入口 → 再关闭。

## 探索性非理想路径

1. 未选择图片时点击文字识别，必须给出可恢复提示，不能生成伪文本。
2. 未勾选人工确认时保存拍题，必须阻止保存。
3. 解释性答案不能由离线规则伪装成自动判定正确。
4. 教师草稿存在内容风险时允许“保存为待审核”，但不能静默通过。
