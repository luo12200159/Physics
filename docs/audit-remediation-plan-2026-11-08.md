# v4.2.0 审查整改计划

依据：`analysis-report.md` 与当前源码核对。本文记录实施边界，不把审查报告中的建议当成已实现事实。

## 现状和裁定

- Windows 手工安装脚本确实漏装多个页面依赖；独立安装器已包含这些文件。现有本机安装目录经核查并未缺少三个教学脚本，报告的该项现场结论已过时。
- Windows 局域网课堂服务的作业提交协议落后于 Android v2；Android 的班级学习汇总、报告快照同样返回空集合，不能宣称已实现完整四维班级汇总。
- 激活码算法是 ECDSA P-256/SHA-256，不是报告所述 RSA-SHA256。免设备码离线授权无法技术性限制复制席位。
- 教材未核验映射、待教师审核草稿与无服务端监护人授权的数据不能自动提升为正式内容或联网能力。

## 实施阶段

1. **交付一致性**：补齐手工安装清单和启动器检查，增设安装资源回归测试；不触碰本机用户数据。
2. **班级协议**：用 Android v2 及现有前端契约为依据升级 Windows 本机课堂服务，保留旧持久化文件兼容；测试提交版本链、批改/退回、权限隔离。
3. **评分安全**：仅对可明确解析的单位、科学计数法与方向扩展自动判分，无法明确解析时继续人工复核；补数值边界测试。
4. **存储性能**：先测量和定位保存路径，再以不丢记录、不改变 state v10 的方式减少全表扫描；增设迁移/回滚测试。
5. **交付**：运行根 QA、服务端测试、Android 双包和 Windows 构建。仅发布经验证的候选版到新的预发布标签，保留旧 `v4.2.0-rc1` 和 `v4.2.0-rc2`。

## 不得伪装完成的事项

签名证书、授权教材小节审定、原生离线公式 OCR、服务端未成年人授权、在线吊销/席位限制、Android WebMessageCompat 迁移及容器化数据库测试需要独立资源或更大范围设计；若本次未达到可验证标准，应在发布说明中列为未完成，不把禁用保护移除。题目 ID、旧学习数据和旧 `.pslab` 必须保持兼容。
