# 费曼物理师生双端 v4.1.0 开发候选说明

## 已实现

- Android 教师端与学生端使用同一题目、班级及作业协议；教师从 1900 道既有完整题中选题，按班级/分组/学生下发。题目 ID 不变。
- 学生查看真实题干、逐题答题、退出后继续本机草稿；不允许仅用“完成”标记代替答案。离线草稿、等待同步和服务端确认分开呈现。
- 教师可查看逐题作答、提交时间与待复核记录，评分/批注后退回；学生可查看反馈并提交新订正版本，旧版本保留供对照。
- 教师班级页新增基于真实成员、作业及复核数据的工作台概况；空数据不生成虚构统计。
- 教师班级页新增班级、作业、学生、知识点四维描述性分析。待人工复核、缺交及空题分不计入均分；知识点少于 3 条已评分题目证据时明确显示“证据不足”，并可查看原始 submission/question 证据 ID。
- 班级提交接口与客户端支持完整分页读取；分页失败时停止生成均分、未交人数和知识点结论，不再把截断数据当作全量数据。Android 教师服务拒绝非有限分数，且逐题评分只能引用本次真实提交中的题目 ID。
- Android 教师本机服务状态格式升级到 v2，兼容读取 v1；PostgreSQL 新迁移为旧提交回填版本。学生学习状态仍为 v10，旧 `.pslab` 导入与既有题目 ID 未改。

## 边界与风险

- 默认没有配置公网 HTTPS 服务。跨设备联动需要教师设备的局域网服务可达，或自行部署并配置受控 HTTPS/PostgreSQL 服务；不能把本机保存说成云端同步。
- 题目级自动评分函数只对答案键明确的单选提供可验证结果，尚未写入正式作业评分流水。开放题仍需教师确认；待批改不算错题。
- 四维学情当前是可追溯的描述性统计，不把少量证据解释为稳定能力或因果性提升。跨任务可比复测、针对性自动新任务、实时课堂互动、完整协同实验、作业模板及草稿编辑尚未全部上线。现有物理实验和学生本机学习能力保留。
- PostgreSQL 集成测试、真实多机网络和 Android 真机安装尚未通过验收。开发候选签名不是应用商店发布资格。旧单体 Android 包与独立双端包包名不同；跨包迁移应使用软件内 `.pslab` 导出/恢复，不会自动复制旧应用私有数据。
