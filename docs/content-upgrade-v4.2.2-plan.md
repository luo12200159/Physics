# v4.2.2 教学内容升级实施记录

本轮以仓库当前 v4.2.1 源码为基线；两份外部评估文档是待核查的建议，不直接作为题目正确或教师审定的证据。保留 1,897 道内置完整题及原有示例题的 ID、state v10、旧 `.pslab` 导入、离线学习与两套 Android 包及 Windows 共用资源。

## 可执行阶段

1. **P0 内容正确性**：为高二静电场、电路的 100 道参数题修正教材册，逐模型核对具体教材节；旧题只更新未被用户编辑的内置副本。为理想模型题明确数值修约口径，去掉不分标量/矢量的泛化“方向”检查句。新增自动 QA，不把未核验目录映射强行标为精确。
2. **教学样板**：在现有八阶段教学序列中补充平均速度、欧姆定律与牛顿第二定律的七段式课程内容和教师追问；对高频错因提供预测—证据—解释—独立复测的原创纠错材料。内容与原始作答证据关联，教师建议仍须教师确认。未审核新题维持草稿，不计掌握证据。
3. **质量审计与交付**：重生成教材映射及待审清单，记录各题型、表征、教材映射、同模板变式与人工评分缺口；运行根 QA、服务端可用测试、双 Android 和 Windows 构建，再在新预发布标签上传三个安装包与校验清单。旧 `v4.2.0-rc1` 不变。

## 不得冒充已完成的事项

未经过两名物理教师复核，不能把新增草稿或 1231 道历史未映射题宣布为已审定。没有实际学生作答与配平复测，不能宣布难度已实测、纠错有效或学习能力提升。无授权或未逐条核验的 2026 年试卷正文不进入题库；公开索引与原创模拟题继续区分。仿真输出不是实际实验数据。
