# 费曼物理内容专项与离线便携授权设计（待确认）

日期：2026-11-04。范围：Android 学生端、Android 教师端和 Windows 共用业务资源；不重做页面布局、配色或导航。本文是实施设计，不代表代码已经完成。

## 已核实的代码基线

- 仓库含可构建源码，而不只是 APK。三端共用 `learning-engine.js`、题库文件、课程目录和 `activation.js`；Android 有独立的学生、教师入口，Windows 由现有发布脚本打包。
- `gradeFinalAnswer` 已有 `answerSchemaVersion: 1` 的选择和物理量评分器；题库基本未配答案规范，参数化题的文字答案与该结构化评分器不匹配。现有 `review-required` 不能转换成错误或正确。
- `curriculum-taxonomy.js` 的人教版目录与题库条目的教材节映射并不一致；旧题目 ID、知识点证据和 `state v10` 必须保留。2024 年义务教育教材与旧版目录并存，不能无提示地以新目录覆盖历史档案。
- 四道“高一·匀变速直线运动”多表征草稿仍是 `待教师审核`，不能计入正式题库、自动评分或掌握证据。
- 当前激活协议为签名的 `PSA1` 码并按设备摘要验证；管理器的现有 CNG 私钥不可导出，不能原样在另一台电脑恢复。
- 工作区已有其他未提交改动；实施时只做增量修改，不重置或覆盖。

## 第一阶段：评分与课程映射止损

1. 在题目生成源头构造强类型答案规范：选项 ID、各小问物理量/数值/单位、题目级绝对和相对容差及必要的方向；不从整段自然语言答案盲猜可评分值。评分入口接收规范化的学生作答，同时保留旧版文本作答和旧记录的读取能力。
2. `autoScorable:true` 仅用于已通过正反例测试、答案规范与题干/解析一致的题。实验论证、作图、开放解释以及无法消歧的复合答案明确进入人工复核；人工复核之前，分数为 `null`，不计正确率分母，也不触发错题或薄弱判断。旧尝试保留原评分版本及证据 ID，不对历史记录静默重判。
3. 建立版本化教材目录映射：区分出版社、修订版、册、章、节；保留现有 ID，增加经核验的 `curriculumVersion`、`curriculumSectionIds`、`knowledgePointId`。只有唯一、官方目录可核对的映射自动确认；跨版本或歧义条目列入教师待审核清单，不用关键词推断冒充已核准章节。
4. 内容质量命令输出逐题报告和汇总：可评分题答案规范覆盖率、真实教材节映射率、歧义/无效/待审核项；阻止“可自动评分但无有效规范”发布。用旧 `state v10` 和旧备份样本验证无损迁移。

## 第二阶段：三个主题的可验证学习闭环

1. 高一匀变速运动先审四道现有草稿：复算数值、方向、公式适用条件，核对 `visualSpec` 与仿真输出；保留草稿身份，只有教师审核后的题目才进入正式证据。课程顺序为“诊断—讲解—预测—仿真—练习—近迁移—远迁移—延迟复测”。“预测”和仿真观察分别保存，仿真结果标注为模型输出，不当作真实实验测量。
2. 在八年级平均速度、九年级欧姆定律建立同结构的原创微课和少量独立题族，覆盖概念、图像/表格、实验数据、定量及迁移。复用已有题库和物理模型，不靠单一模板的参数替换堆积独立诊断证据。
3. 将已有错误类型映射到可审核的补救讲解、反例、近迁移和延迟复测；教师端给出依据真实 evidence ID 的作业建议，教师确认后才形成教学决定。无足够证据时显示“证据不足”，不能给出稳定能力标签。

## 离线便携授权（用户已选择）

- 旧设备绑定 `PSA1` 码继续被新客户端接受；新增签名覆盖的便携授权范围字段，使新码不需要设备码，且可由签发人指定有效天数或永久。码仍使用原 `PSA1.<payloadBase64Url>.<signatureBase64Url>` 包装；旧码验签与设备规则不放宽。
- 签发管理器在新电脑运行时需导入单独加密的签发私钥归档；归档不放入 GitHub、APK 或安装包。现有不可导出的旧私钥保留用于历史码，新建可迁移签发密钥并把其公钥纳入三端可信公钥表。用户指定的固定登录口令只作为管理器界面解锁；发布的开源二进制/哈希不能让该口令成为真正的签发权限，私钥归档及其独立强口令才是安全边界。不得在源码、日志、测试报告中写入明文登录口令或私钥。
- 离线便携码可被复制到多台设备；在没有在线核销服务的前提下，不能声称“一码一机”或跨机器撤销。客户端仅校验签名、产品、范围与有效期；用户数据与激活码不绑定。激活页面只做必要的文字/字段调整，不改变视觉设计。

## 验证、迁移与发布

- 先写失败测试，再逐项实现。包括旧码兼容、新便携码跨两种设备 ID 验证、篡改/过期拒绝、签发归档恢复、结构化答案正反例、开放题人工复核、教材映射、四道草稿物理量复算和旧记录迁移。
- 每阶段交付“修改文件 / 实际测试命令及结果 / 题目映射覆盖报告 / 教师待审核清单 / 未解决问题”；没有教师签字、真机或三端端到端验收的项目明确标成未验证。
- 构建三端候选包并核对包内共享业务资源；未具备正式签名密钥时标为开发候选。GitHub 上传仅包含源码中的非秘密材料、候选包和必要校验值；上传前检查密钥/归档/口令均不在提交中。不能把本地构建等同于 GitHub 发布成功，需核实远端提交和发布资产。

## 主要风险和验收边界

- 教材版本以官方目录为准：义务教育 2022 课程标准和 2024 教材目录见教育部公开文件，高中教材需按实际使用版次核对。已有章节 ID 不变，无法可靠映射的题目如实列为待核验。
- 题库逐题的教学科学性和教师审核不能由单次自动 QA 取代。新草稿未审核前不能变成正式评价证据。
- 离线签发密钥若归档丢失，无法在另一台电脑继续用同一密钥签发；若归档泄露，需密钥轮换，已发离线码无法即时撤销。
- 未成年人线上 AI 同意和服务端校验保持现状，不因本次内容改造而绕过。
