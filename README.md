# 费曼物理
当前学生端开发候选版本：v4.0.2（用户所述“4.02”按既有三段式版本命名）。Android 学生端与教师端仍为独立安装包，共享题库、学习引擎、备份格式、变式生成器和班级协议。

一个可安装、离线优先且支持真实联机班级的初高中物理学习应用。v4.0.0 不改变既有题目 ID，并以向后兼容的 state v10 承接 v3.4.1 的 state v9 与 `.pslab` 数据。旧单体 Android 包 `com.physicsstudio.studyroom` 不会被新包覆盖；旧数据须先从旧应用导出 `.pslab`，再按身份导入学生端或教师端。班级创建、加入、成员列表、作业下发、邀请码轮换和删除均以班级服务确认结果为准，不用本机假状态冒充联网成功。

项目继续保留 Windows 版；Android 两个独立包分别使用 `com.physicsstudio.student` 和 `com.physicsstudio.teacher`，可安装在同一设备上。

## 4.0.2 学生端审计修复

- 解析格式化只移除明确的“第 n 步”标签，保留小数、负数和公式开头。四道受影响内置题的旧文本通过精确旧内容校验迁移；自改解析不覆盖，题目 ID 与学习证据不变。
- 自动判题对单位、量纲、方向、负号、文字否定和多选作答采取明确比较；缺少可靠结构化规范的解释/混合答案进入人工复核。旧自动判对而新规则无法确认的记录在首次启动后保留原评分与原始作答，并标记待核验，不计入正式正确率。
- 串并联电路的数值和连线读取同一拓扑；零电压、运动时间边界及波幅缩放不再静默使用示例默认值。规则校验是形成性证据，不是标准化能力分数。
- 学习状态增量提交 IndexedDB；需要“已保存/已完成”的学生操作等待提交回执。安卓完整备份等待系统文件写入回执，取消或失败不报告成功。旧 `.pslab` 仍可恢复；恢复前限制 ZIP 条目数量与声明大小。
- IndexedDB 主存储读取失败时进入只读故障状态，不自动以陈旧迁移备份覆盖学习记录；事务/配额写入失败不会把未保存的缓存展示为已保存。完整 `.pslab` 同时包含完整题与题源记录，恢复时分类型校验。
- 无摸底记录不显示 0/0 覆盖，也不默认安排挑战题；跨日期掌握还要求至少间隔 24 小时。这是可配置产品规则，不是教育测量标准。
- AI 服务地址或健康检查不再等同于学生联网辅导可用；服务端缺少持久授权核验时学生内容不发送，本机提示仍可使用。
- 学习 state 仍为 v10，1900 道完整题的既有 ID 保持不变。Android 单文件完整备份目前上限 100 MiB，大型媒体需要在正式发布前提供分卷或流式路径；本候选版没有声称完成这一能力。

发布前仍需真机验证：低内存设备的备份取消/写入失败、安装覆盖升级、TalkBack 与字体放大、后台恢复、摄像头权限和旧档案恢复后附件哈希。无正式签名密钥的 APK/Windows 安装器只作为开发候选，不代表商店发布就绪。

本地 `npm run qa` 与服务端类型检查、单元测试、生产构建通过。服务端 5 个 Testcontainers 集成套件因本机无 Docker/Podman 在容器启动前失败，15 项断言未执行，不记为通过。

## 4.0.0 学生端学习闭环升级（基于 v3.4.1）

- 学生一级导航调整为“首页、课程、训练、学情、我的”。首页只突出下一步任务、到期复习、错题订正和费曼自我讲解；完整题库、实验室、模型和工具仍可从训练与课程进入，并未删除。
- 形成性学情报告只使用真实已评分作答，待人工复核不进入正确率分母。知识点至少有 3 条已评分证据后才进入“较稳定/需巩固”候选；结论保留 evidence ID，且明确不是标准化测评分数。
- 新增费曼自我讲解记录：学生用自己的话说明研究对象、过程、规律、条件、类比和条件变化预测。该记录用于反思与建议，不因填写文本自动形成掌握证据。
- 错因统一为 8 类：概念理解、研究对象/建模、规律选择或适用条件、图像与表征、公式与代数、单位/方向/符号、实验与数据处理、审题或计算疏漏。旧版六类标签在读取时兼容映射。
- 变式证据角色统一为 `core / near / far / counter`，旧 `reverse / context` 迁移为 `far` 并保留 `variantTechnique`，不改原有题目、变式和作答 ID。题库缺少真实远迁移或反例时会如实只提供已校验近迁移，不伪造题型。
- 首页快捷操作、形成性报告建议和教材册标签改为可触控横向滚动；各主页面保持纵向滚动，按钮均接入题目、诊断、训练、学情、模型或设置等真实动作。

学生端构建：

```powershell
.\android\tools\build_android.ps1 -Edition student
```

## 3.3.0 专项变式训练

- 新增独立 `variant-generator.js`。生成链路为“母题结构化 → 变式规划 → 完整试题 → 独立校验 → 审核/缓存 → 学生作答”，不再把“改变条件、逆向设问、情境迁移”的文字建议冒充完整题目。
- 默认生成近迁移、逆向/结构迁移和情境/表征迁移三类变式；第三题不满足质量门禁时只返回两题。内置题优先使用已审核题模和专项题，离线又没有可核验题模时明确提示当前无可验证完整变式。
- 每道变式包含题干、题型、知识点、难度、变化说明、标准答案、结构化分步解法、结果检验和验证状态。AI 题经 `/v1/physics/generate-variants` 生成后再进行独立交叉验证；关键校验不通过或结论不确定时必须进入教师审核，不能直接下发。
- 教师可在同一预览中审核、编辑、重生成、批准并加入分层作业；常用参数可保存为本机 preset。学生必须先作答，提交后才显示解析；主动查看完整解法统一记为第 5 级提示，不计独立迁移证据。
- 学习状态新增兼容的 `variantSets`、`variantAttempts` 和 `variantPresets`。只有通过验证且低提示独立正确的变式作答才形成迁移证据；旧 `transferNotes` 继续可读，但未经既有验证或教师确认不会抬高掌握状态。
- 教师批准的变式集及专项作业纳入班级增量同步；离线作答进入待同步队列，恢复联网后去重发送。母题内容变化会使旧变式缓存标记为过期，但历史作答仍保留。

## 3.2.0 学习闭环升级

- 到期复习只能从真实作答入口完成；主观难度和信心单独保存，不再直接改写复习到期时间。第 5 级完整解法不计为独立完成证据，旧 `reviews` 数据继续兼容。
- 受控 AI 导师优先调用 `/v1/physics/tutor-turn`，每轮只推进一个主要认知步骤；网关不可用时退回本地五级提示，不阻断离线学习。客户端不保存 OpenAI API Key，发送前只保留本题必要且已脱敏的信息。
- Android 原生桥已提供 `getOcrCapability` / `ocrImage` 能力协商接口；当前无 Gradle 依赖的 `android.jar + javac` 构建未捆绑离线 OCR 引擎和模型，因此会明确返回不可用，并按“原生能力 → 浏览器 `TextDetector` → 人工录入”降级。任何识别文本仍须学生确认，不能把公式、上下标、矢量或复杂图示自动补全为可靠题干。
- 离线物理表征覆盖受力图、运动图像、电路图、实验散点拟合和基础光路图；交互模型覆盖抛体、斜面、电路以及匀变速运动、牛顿第二定律、机械能、碰撞和波动。模型操作本身不自动形成掌握证据。
- 九年级、高三既有 400 道专项题及 `core / near / far / counter` 结构保持不变；八年级、高一、高二只报告已审核内容的真实覆盖缺口，不以同模板改数字冒充独立诊断证据，也不自动发布生成题。
- 教师“按薄弱点生成分层作业”先显示学生范围、知识点、证据、题目来源和数量，必须经教师确认后才形成待发布作业；AI 不得绕过教师审核。

## 2.9.0 正确性升级（v3.0 兼容基础）

- “是否完成摸底”只由独立的 placement assessment session 决定。普通练习、错题、单条诊断、广覆盖检查或试卷记录都不会自动变成“已完成摸底”；旧档案没有明确 session 时显示“历史状态待确认”，不会猜测完成。
- 每名学生在首次迁移时获得永久 `portableProfileId`。同名学生不会自动合并，多学生试卷导入按“稳定学生 ID + 试卷 ID”隔离；无法匹配的行停留在异常预览，不会写入当前学生。
- 待人工复核作答保留提交、答案、建模和时间证据，但在教师确认前不进入正确率、平均分、趋势、错题推荐或薄弱判定；无可评分证据显示“暂无可评分证据”。
- 干预前后只比较同知识点、同模型或等价组、同难度、不同题目的配对证据。1～2 对仅显示“改善迹象、尚需复测”；达到可配置的 3 对且跨 2 个日期后，才显示描述性百分点变化。该规则不是标准化测评阈值，也不证明因果性能力提升。
- 高频实体 `attempts`、诊断、试卷、成长记录、导入报告、实验记录和 assessment session 使用 IndexedDB 分库存储。升级时先保留旧 JSON 备份，再事务迁移；失败会明确提示“数据未保存”，不会静默丢失。
- 教师中心按“今日、学生、班级、管理”组织。今日只显示可处理异常；系统推断、原始证据和教师确认分开，AI 建议不能直接修改正式评分或掌握状态。

## 使用方法

1. 本机开发目录可双击 `安装应用.cmd`；复制到其他 Windows 10/11 电脑时，请使用当前发布目录中的最新版安装程序。
2. 单文件安装程序包含应用及局域网班级服务，会安装到当前 Windows 用户目录，并创建桌面、开始菜单和“已安装的应用”卸载入口。
3. 安装完成后，从桌面或开始菜单打开“费曼物理”；首次打开会显示设备申请码，取得所有者签发的一机一码后才能进入。
4. 点击“添加试题”，填写题目、解题方法和答案。
5. 可上传 MP4、WebM、MOV 视频，或填写浏览器可直接播放的视频链接。
6. 题目、本地视频、扫描图片与附件保存在浏览器本地数据库中，不需要本地服务器。

应用安装位置为 `%LOCALAPPDATA%\Programs\物理研习室`。重新运行 `安装应用.cmd` 可覆盖安装应用文件，不会主动清除已保存的浏览器本地数据。

桌面版使用 WebView2 和稳定的 `https://physics-studio.local` 本地来源，用户数据目录固定在 `%LOCALAPPDATA%\物理研习室\UserData`。外部网页优先交给 Microsoft Edge；没有 Edge 时使用 Windows 默认浏览器。若电脑缺少 WebView2 Runtime，启动器会明确提示并允许改用浏览器打开。

### 局域网多设备班级

1. 任意受支持的 Windows 电脑或 Android 手机均可作为班级主机。教师打开“费曼物理”并保持运行；内置服务监听 TCP `8788`，设备发现使用 UDP `18788`。为兼容旧版，Windows 数据仍位于 `%LOCALAPPDATA%\物理研习室\ClassroomService`，Android 数据位于应用私有目录。
2. Windows 首次提示防火墙访问时，只允许“专用网络”。教师与学生设备必须连接同一可信 Wi-Fi/局域网；服务端会校验来源地址属于主机同一 IPv4 子网。访客网络、AP 隔离、VPN 路由或防火墙拦截会阻止设备互访。
3. 教师仅输入非空班级名称即可创建。创建后立即得到 UUID 班级 ID、22 位随机学生邀请码和二维码；教师管理凭据不会进入邀请码、二维码或分享文本。
4. 学生无需登录名或密码，只需填写备注名并输入邀请码，或扫描/选择二维码图片。三种入口都调用同一服务端加入流程，成功后由服务端返回班级和成员身份。
5. 二维码采用紧凑结构 `physicsstudio://join?c=<CLASS_ID>&i=<INVITE_CODE>&s=<LAN_IP>`；旧版 `class_id/code/server` 格式继续兼容。二维码中的地址只用于定位同一局域网服务，不授予教师权限。
6. 教师下发的班级作业、成员关系、分组与邀请码由主机持久化；同一局域网设备重新连接后从主机读取。一个班级已自动化验证 9 个不同设备身份并发加入；协议和存储没有两台设备限制。实际可连接数量仍受主机性能、路由器容量及网络策略影响，不能据此承诺公网或五万人并发。

当前安装包没有内置公网中继。跨城市、蜂窝网络或不同局域网使用，需要另行部署 `server/` 的 HTTPS 服务并配置正式域名；不能把同一局域网能力描述为公网云服务。

## 一机一码与所有者签发工具

- 用户端只内置 ECDSA P-256 公钥。激活码签名私钥没有写入安装包、APK、源码包或管理器 EXE。
- 激活码管理器只会使用当前 Windows 用户 CNG 密钥库中与发布公钥匹配的不可导出私钥；当前构建环境未能访问该私钥，因此本次构建未验证签发流程。不得重新初始化同名密钥，否则会改变发布公钥并使既有激活码失去兼容性。私钥可用时，签发能力仍取决于对应 Windows 账户及其密钥库访问权；所有者需保护 Windows 登录、磁盘和远程访问权限。
- Windows 设备摘要由随机设备秘密经 SHA-256 得到，设备秘密使用当前用户 DPAPI 保护；Android 设备摘要基于应用包名和系统提供的 `ANDROID_ID` 再做 SHA-256。设备申请码不包含学生档案、题库内容或原始标识。
- 管理器位于 `发布\仅限管理员\费曼物理-激活码管理器-v1.0.0.exe`。日常使用时逐行粘贴设备申请码，可一次生成最多 1000 个设备绑定激活码，并导出 CSV。
- 当前可信发布公钥 SHA-256 指纹为 `25E1061D80D59277D19299221BA8ED82CD5E3EBA8BA740B736AB070FA5F8D4C6`。用户端构建前应核对 `activation-public-key.js` 与该指纹一致；2.9.0 客户端仍保留上一发布公钥的验签兼容，但新激活码只由当前密钥签发。
- 一个激活码只能通过其签名中的设备摘要在指定设备上使用，复制到第二台设备会校验失败。纯离线方案不能在应用被彻底清除后跨设备集中记录“已兑换”；若要实现服务器端全局一次核销、吊销和设备换绑，需要部署联网激活服务。
- 当前机制用于正常安装环境中的发行控制，并非不可破解的 DRM；能够修改客户端二进制或脚本的攻击者仍可能绕过本地界面限制。更强的防篡改需要 Windows 发布者签名、服务端核销和完整性校验协同实现。
- 不要把 `发布\仅限管理员` 目录交给普通用户。即使他人在另一账户初始化同名新密钥，新密钥生成的代码也不会被当前用户端公钥接受，但管理器仍应按发行凭据管理。

## 能力边界

- Windows 与 Android 安装包均内置局域网班级服务，适合由一台教师电脑或手机在同一 Wi-Fi/局域网内承载班级。仓库中的 `server/` 仍是 PostgreSQL/Redis/HTTPS 托管部署方案；只有实际部署并配置正式域名后，才支持跨网络访问。两种模式都只同步班级、成员、分组和班级任务，题库、附件和完整学习证据仍默认保存在本机，不能表述为学习数据已自动云同步。
- 安装版不会把 `localhost`、`127.0.0.1` 或 `appassets.androidplatform.net` 当作其他设备可访问的地址。Windows 原生宿主与 Android 原生桥只允许固定端口上的回环/私有网段班级请求；公网服务必须使用 HTTPS。服务不可达时，本机学习记录仍可离线使用，但建班/入班不会被伪装为成功。外部搜索和网页打开优先交给 Edge，未安装 Edge 时回退系统默认浏览器。
- 拍照、附件和草稿板负责采集原始材料；当前版本不声称已可靠识别手写公式、受力图、电路图、光路图或实验图的物理语义。
- 客户端已提供 ChatGPT 分步解题和文档解析入口，源码中的 `server` 目录提供基于 OpenAI Responses API 的受控服务端参考实现。API 密钥只能放在服务端；未配置受控服务端时，解题按钮默认调用 Edge/Bing 检索题干、知识点与分步校验要求，同时保留离线规则反馈，不声称外部搜索就是 ChatGPT，也不把搜索结果直接作为学情证据。
- 当前内置 1900 道完整本地题：八年级 300 道、九年级 500 道、高一 300 道、高二 300 道、高三 500 道。其中包含 1416 道基于 75 个物理模型模板形成的原创参数变式，以及 400 道“物理研习室原创·长沙模拟考结构适配专项”；九年级和高三专项各 200 道。所有完整题均有题干、答案和分步解析。应用还保留 232 条近六年真题题号与考点索引，因此数据库总记录数为 2132。
- 新增 400 道专项题为应用内原创，按母题、条件变化、跨情境迁移和反例辨析组织；它们只适配长沙模拟考常见结构，并非长沙学校模拟卷原题，未复制第三方试卷题干、图像或答案。
- 1416 道新增题均标注“物理研习室原创·长沙课程适配练习”，题干文本不重复，但它们不是长沙官方真题或教材原题。公式、数值范围、必填字段和重复项已自动校验，内容状态仍提示教师抽检。
- 解释题、证明题、复杂多问和自由书写的中间步骤会明确进入人工复核；不会以关键词匹配冒充正确判定。
- 建模评分是用于形成性反馈的本地规则量表，尚不是经过心理测量学验证的标准化考试分数。
- 传感器实验结果取决于设备硬件、系统 WebView 和用户授权，手机传感器不是计量认证仪器。

## v3.1.2 在线班级、证据诊断与交互性能

- 教师默认工作流为“今日 → 学生 → 班级 → 管理”：先处理未摸底、待人工复核、专项完成待复测和到期复习等行动项，再进入高级维护工具。
- 新建在线班级只需填写班级名称。客户端只发送 `{name}`，服务端继续兼容旧版年级与学科字段；创建成功后立即进入班级。未登录本机教师通过 `/v1/classes/anonymous` 获得仅绑定该班级的 owner capability，已登录教师继续使用 bearer 会话；两者都不需要教师邀请码或管理员预创建账号。
- 已登录用户的兼容接口也不再把全局 `teacher` 角色作为建班前置条件；创建动作本身建立该用户对新 `class_id` 的 owner/teacher 作用域。家长账号仍受 guardian 权限边界限制，其他班级仍按 class_id 隔离。
- 邀请码只授予学生加入权限，二维码内容为 `physicsstudio://join?class_id=<UUID>&code=<22-char-code>`；owner token 不进入邀请码、二维码、分享文字或学生加入请求。刷新邀请码仍由服务端按 class_id 校验 owner 权限。
- 教师界面不再要求填写邀请有效期和使用次数；客户端使用服务端允许的长期默认值，后端仍保留到期、上限、频率限制、角色校验与审计，防止邀请码长期失控或被批量猜测。
- 托管部署可设置 `window.PHYSICS_STUDIO_CLASSROOM_URL`，或在登录时填写服务地址；同源 HTTPS 部署会自动优先使用当前站点。未配置或网络不可用时，应用保留本机离线学习与本地档案，不伪装为云同步。
- 在线班级权限由服务端账号角色决定；本地教师 PIN 只保护当前设备上的教师管理功能，不能替代云端鉴权。
- 报告中的“达标/部分达标/未达标/证据不足”均为形成性证据结论；只有可匹配的同知识点、同模型/等价组、同难度、不同题目证据才显示前后百分点变化。
- 在线请求使用 15 秒超时和一次 GET/HEAD 重试；写操作不自动重试。服务不可达时保留本机数据并显示离线状态，网络恢复后再刷新/发送待同步队列。
- Windows 启动器使用 Edge WebView2 承载本地应用，外部检索优先调用 Microsoft Edge 可执行文件，找不到时才回退系统默认浏览器；应用不会抓取 Edge/Copilot 页面伪造答案。受控 AI 网关可在脱敏后结合真实学习诊断上下文生成解释。
- `buildStudentLearningDiagnosis` 只统计真实 attempts：按 knowledgePointId 汇总提交数、已评分数、正确数、正确率、近期/历史正确率、重复错误、作答时长、最近练习时间和趋势；样本不足时明确显示“当前样本不足，暂不做稳定结论”。
