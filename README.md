# 物理研习室

一个可安装、可离线使用的初高中物理学习应用。2.6.0 版覆盖八年级、九年级和高中三个年级段，把 1900 道完整本地题、完整学生学习中心、文档解析、学生档案、每日测试与受控 ChatGPT 解题接入同一学习闭环，并采用设备绑定激活。

项目同时提供 Windows 版和独立 Android 版；两个版本并列保留，互不覆盖。

## 使用方法

1. 本机开发目录可双击 `安装应用.cmd`；复制到其他 Windows 10/11 电脑时，请使用 `发布\物理研习室-安装程序-v2.6.0.exe`。
2. 单文件安装程序包含应用所需的全部文件，会安装到当前 Windows 用户目录，并创建桌面、开始菜单和“已安装的应用”卸载入口，不需要管理员权限。
3. 安装完成后，从桌面或开始菜单打开“物理研习室”；首次打开会显示设备申请码，取得所有者签发的一机一码后才能进入。
4. 点击“添加试题”，填写题目、解题方法和答案。
5. 可上传 MP4、WebM、MOV 视频，或填写浏览器可直接播放的视频链接。
6. 题目、本地视频、扫描图片与附件保存在浏览器本地数据库中，不需要本地服务器。

应用安装位置为 `%LOCALAPPDATA%\Programs\物理研习室`。重新运行 `安装应用.cmd` 可覆盖安装应用文件，不会主动清除已保存的浏览器本地数据。

桌面版使用 WebView2 和稳定的 `https://physics-studio.local` 本地来源，用户数据目录固定在 `%LOCALAPPDATA%\物理研习室\UserData`。外部网页优先交给 Microsoft Edge；没有 Edge 时使用 Windows 默认浏览器。若电脑缺少 WebView2 Runtime，启动器会明确提示并允许改用浏览器打开。

## 一机一码与所有者签发工具

- 用户端只内置 ECDSA P-256 公钥。激活码签名私钥没有写入安装包、APK、源码包或管理器 EXE。
- 可信私钥已经创建在当前 Windows 用户的 CNG 密钥库中，并设置为不可导出。能否签发取决于该 Windows 账户及其密钥库访问权；软件本身不能据此证明操作者的自然人身份，因此所有者仍需保护 Windows 登录、磁盘和远程访问权限。
- Windows 设备摘要由随机设备秘密经 SHA-256 得到，设备秘密使用当前用户 DPAPI 保护；Android 设备摘要基于应用包名和系统提供的 `ANDROID_ID` 再做 SHA-256。设备申请码不包含学生档案、题库内容或原始标识。
- 管理器位于 `发布\仅限管理员\物理研习室-激活码管理器-v1.0.0.exe`。日常使用时逐行粘贴设备申请码，可一次生成最多 1000 个设备绑定激活码，并导出 CSV。
- 当前可信发布公钥 SHA-256 指纹为 `25E1061D80D59277D19299221BA8ED82CD5E3EBA8BA740B736AB070FA5F8D4C6`。用户端构建前应核对 `activation-public-key.js` 与该指纹一致；2.6.0 客户端仍保留上一发布公钥的验签兼容，但新激活码只由当前密钥签发。
- 一个激活码只能通过其签名中的设备摘要在指定设备上使用，复制到第二台设备会校验失败。纯离线方案不能在应用被彻底清除后跨设备集中记录“已兑换”；若要实现服务器端全局一次核销、吊销和设备换绑，需要部署联网激活服务。
- 当前机制用于正常安装环境中的发行控制，并非不可破解的 DRM；能够修改客户端二进制或脚本的攻击者仍可能绕过本地界面限制。更强的防篡改需要 Windows 发布者签名、服务端核销和完整性校验协同实现。
- 不要把 `发布\仅限管理员` 目录交给普通用户。即使他人在另一账户初始化同名新密钥，新密钥生成的代码也不会被当前用户端公钥接受，但管理器仍应按发行凭据管理。

## Android 版

1. Android 安装文件位于 `发布\Android\物理研习室-Android-v2.6.0.apk`。
2. 支持 Android 6.0 及以上手机和平板，可离线打开题库并保存学习数据。
3. Android 版可调用摄像头拍题、识别二维码、选择多张图片与文档；经设备授权后可调用麦克风和可用的运动、光照、磁场传感器。
4. Android 与 Windows 的本地数据库相互独立；完整 `.pslab` 备份可迁移题目、学习档案、附件与视频，轻量 JSON 用于仅迁移结构化内容。
5. Android 原生工程位于 `android`，不会替换或删除现有 Windows 安装程序。
6. Android 的联网题库、Edge/Bing 搜索和外部网页优先调用 Microsoft Edge；未安装 Edge 时交给手机当前的默认浏览器。
7. Android 版与 Windows 版使用同一发布公钥，但设备申请码不同；每台设备都需要单独签发激活码。

## 2.6.0 学生学习中心、学习闭环与角色模式

- 首次启动：只选择学生、教师或家长身份，以及年级、教材版本和近期目标；可随时在设置中切换。
- 学生首页：突出一项下一步学习任务、15 分钟建议、待复习/错题/新知识和本周有效练习目标，同时提供完整学习中心入口；一级导航固定为“今日、练习、错题、我的”，拍题为悬浮入口。
- 学生完整模块：题库、错题集、方法视频与动态讲解、已掌握、掌握进度、教材知识点、本人学情分析、学习实验室和学习建议均为可独立浏览和继续操作的页面。
- 教材知识目录：覆盖人教版八年级至高中选择性必修共 10 册、55 章、231 节；每节至少列出四项核心概念、公式条件、实验或易错要点，并可进入对应练习。
- 题目详情：题干、考察点、结构化分步解析、解析结论、结果复核和参考答案分区呈现；学生模式不能进入题库编辑。
- 方法讲解：有真实视频附件时直接播放；没有视频时提供基于题目现有解析的逐步动态讲解，并明确标注其不是录制视频。
- 学生拍题：支持拍照、选图、粘贴截图、估算裁边和对比度增强；只有设备真实提供本地文字检测接口时才尝试 OCR，且所有识别文字必须由学生确认，不声称可靠识别公式或图示语义。
- 教师模式：保留题库编辑、来源记录、授权状态、导入导出、组卷、内容审核和学生档案汇总；学生首页不显示这些管理功能。
- 家长模式：只显示学习时长、正式作答、复习情况、独立完成率和可支持模块，不显示排名或负面能力标签。
- 默认安全：学生模式只搜索站内题目，外部网站访问默认关闭；教师或家长明确开启后，才显示带离站风险提示的 Edge/Bing 入口。

- 前概念诊断：内置 8 组原创诊断题，使用“答案＋理由＋置信度”区分稳定错误观念、猜对、尚未理解和概念稳固。
- 苏格拉底式分步导师：要求先填写研究对象、已知量、未知量、过程划分、理想化假设、坐标系、受力、方程条件和合理性检验，再按顺序解锁五级提示；支持保存一张本机草稿图片。
- 可核查反馈：选择题和可唯一提取的数值题由离线规则自动比较；反馈定位到选项、数值、单位、符号或缺项，并给出下一步修改方法。
- 九项校验面板：分别显示结论、单位、方向、量纲、数量级、守恒条件、极限、图像一致性和第二种方法的状态。只有规则真正验证的项目标为“自动通过”，其余明确标为待复核。
- 同步建模画布：平抛/斜抛、斜面动力学和线性直流电路使用同一组变量同步更新物理图示、运动图像、方程和数值；均注明理想模型假设。
- 迁移训练：为母题生成结构迁移、跨情境和反例辨析任务，保存学生写出的模型、适用条件和关键方程。
- 学情与复习：记录正确率、独立完成率、提示层级、训练时长、错误类型、九项建模证据、自我解释和置信度；必须完成一道迁移记录后才安排本轮间隔复习。
- 证据化掌握：状态统一为“未开始、学习中、熟练、已掌握、待复习、薄弱”。至少一次低提示正确为“熟练”；不同日期低提示独立正确至少两次并完成一道迁移记录，才进入“已掌握”。阈值属于试运行产品规则，不是教育测量标准。
- 物理工具：20 条公式及适用条件、常数表、单位换算、量纲校验、二维矢量、线性拟合和可导出 PNG 的物理图示草稿板。
- 教师中心：从完整题干记录中生成待审核分层作业，审核内容来源，导入学生学习档案并汇总班级薄弱点。
- 学生管理：教师可添加、编辑和删除学生，记录学段、年级、目标与分析备注；试卷成绩和教师观察形成可导入、导出的成长时间线与描述性分析报告。
- 每日课后测试：按学生、日期和年级稳定生成默认 5 道、最多 8 道练习，优先安排到期复习、本人错题、试卷薄弱点、高提示依赖和低建模证据题；只使用当前年级已发布题目。
- 文档解析：DOCX 纯文本可离线拆题，设备提供文字检测时可离线预识别图片；PDF、旧版 Word 和复杂扫描卷经配置的受控服务端解析。候选题必须人工确认并进入教师审核队列。
- 内容目标：1900 题只统计同时具备题干、答案和分步解析、可离线作答的题目；其中八年级 300 道、九年级 500 道、高一 300 道、高二 300 道、高三 500 道。232 条近六年真题题号索引不计入。原创题和教师已核验真题分别标注，不能用原创题冒充官方真题。
- 内容质量检查：保存题目前检查题名与设问、缺图或缺项、答案单位、公式条件、学段年级、教材分类和来源记录；只提示风险，不替代教师审核。
- 手机实验室：支持设备可用性检测、加速度与声音频谱采集，并尝试调用环境光、磁传感器；可导出 CSV、计算均值和样本标准差、保存探究记录。

学习闭环数据另存于本机浏览器存储。可导出轻量学习档案，也可通过完整 `.pslab` 备份连同本地视频、扫描图片和文档附件一起迁移。

## 能力边界

- 当前安装包没有云账号、自动跨端同步、学校统一身份认证、集中权限和审计服务。跨设备使用 JSON 文件手动迁移。
- 拍照、附件和草稿板负责采集原始材料；当前版本不声称已可靠识别手写公式、受力图、电路图、光路图或实验图的物理语义。
- 客户端已提供 ChatGPT 分步解题和文档解析入口，源码中的 `server` 目录提供基于 OpenAI Responses API 的受控服务端参考实现。API 密钥只能放在服务端；未配置服务端时应用自动使用离线规则，不声称已经调用 ChatGPT。
- 当前内置 1900 道完整本地题：八年级 300 道、九年级 500 道、高一 300 道、高二 300 道、高三 500 道。其中包含 1416 道基于 75 个物理模型模板形成的原创参数变式，以及 400 道“物理研习室原创·长沙模拟考结构适配专项”；九年级和高三专项各 200 道。所有完整题均有题干、答案和分步解析。应用还保留 232 条近六年真题题号与考点索引，因此数据库总记录数为 2132。
- 新增 400 道专项题为应用内原创，按母题、条件变化、跨情境迁移和反例辨析组织；它们只适配长沙模拟考常见结构，并非长沙学校模拟卷原题，未复制第三方试卷题干、图像或答案。
- 1416 道新增题均标注“物理研习室原创·长沙课程适配练习”，题干文本不重复，但它们不是长沙官方真题或教材原题。公式、数值范围、必填字段和重复项已自动校验，内容状态仍提示教师抽检。
- 解释题、证明题、复杂多问和自由书写的中间步骤会明确进入人工复核；不会以关键词匹配冒充正确判定。
- 建模评分是用于形成性反馈的本地规则量表，尚不是经过心理测量学验证的标准化考试分数。
- 传感器实验结果取决于设备硬件、系统 WebView 和用户授权，手机传感器不是计量认证仪器。

- 国家中小学智慧教育平台：教育部建设的官方免费资源平台，覆盖物理课程、基础作业、在线组卷和部分解析视频。

- “搜索互联网最新资料”会按照选定年份、学段和关键词打开定向搜索结果。

这些站点没有统一开放接口，程序不会绕过网站登录、下载限制或版权声明，也不会把第三方网页内容自动复制到个人题库。页面是否免费、是否需要注册及下载条件可能变化，应以打开后的站点提示为准。

- “下载授权题库导入模板”会生成 JSON 字段规范；取得许可后可批量填充题目、解析、答案、来源及教材知识点编号。
- 互联网检索结果不是可证明的全集。应用保存已核验来源和定向搜索能力，来源清单需持续维护。

## 2020—2025 年长沙中考与湖南适用高考真题

- 题库保留 2020—2025 年共 12 套试卷的 232 条题号级考点索引：长沙中考 141 题、湖南适用高考物理 91 题；“题源”同时保留原卷入口。
- 2020 年高考按当年湖南实际使用的全国卷Ⅰ物理部分收录；2021—2025 年为湖南省选择性考试物理卷。
- 每条记录包含原题号、题型、考察点、试卷范围说明和可点击的原卷入口，并继续显示在题库中。
- 公开可访问不等于已经取得完整内容再发行许可。安装包不复制许可状态未明确的完整题干、图形和答案，打开来源后可查看原卷；索引不会猜填缺失条件或答案。
- 2026 年试卷在当前核验日尚不具备“完整试卷、完整答案、稳定公开来源”三项条件，因此“近 6 年”采用最近六个资料完整年度 2020—2025。

## 长沙中考与湖南高考原创模拟卷

- 内置 2 套原创综合训练卷，共 38 道完整题：长沙中考物理 23 道、湖南高考物理 15 道。
- 每题均提供完整题干、分步解题方法、详细答案和考察点，可离线搜索、加入错题集、记录掌握进度及添加讲解视频。
- 训练卷依据相应课程标准和长沙、湖南物理复习知识结构原创编写，不冒充官方试卷或第三方模拟卷。
- 旧版本中的第三方模拟卷等仅链接记录会移到“题源”；2020—2025 年中高考真题题号与考点索引作为明确例外继续保留在题库。

应用的个人题库、题目编辑、扫描附件、筛选、掌握进度、本地视频播放及导入导出功能可以离线使用；“互联网题源”中的第三方网页和互联网搜索需要联网。

## 数据说明

- “完整备份”生成 `.pslab` ZIP，包含清单、题库、学习档案、附件和视频；每个文件记录 SHA-256、大小和 MIME，恢复时全部校验后再事务写入，失败会回滚。
- “轻量 JSON”只迁移题目文字、视频链接、附件清单和结构化学习记录，不包含 Blob 文件。
- 安装版与直接打开 `index.html` 使用的来源不同。首次迁移应在旧页面导出，再在 2.6.0 版恢复；重要资料仍建议另存原文件。

## 功能

- 使用所有者签名的一机一码激活 Windows 与 Android 用户端，并由独立管理器批量签发
- 添加、编辑、删除物理试题
- 使用摄像头拍照扫描题目，或从相册上传多张试题图片
- 使用摄像头或二维码图片识别网页链接、题目文字和物理研习室 JSON
- 通过文件选择、拖拽和剪贴板粘贴添加 PDF、Word、TXT、Markdown 与图片附件
- 记录题目内容、解题方法、答案、来源、知识点、学段和难度
- 上传本地解题视频或关联视频直链
- 在试题卡片中直接播放已关联的方法视频，无视频时可从卡片进入编辑添加
- 按关键词、学段和难度筛选
- 在题库中搜索近六年真题的年份、题号、试卷名和逐题考察点，并可从详情打开原卷入口
- 使用同一搜索框检索站内题目、解析、答案等内容，或通过 Edge/Bing 搜索外部网站
- 点击统计卡片跳转到全部试题、方法视频、已掌握或掌握进度视图
- 按跨日独立正确、提示依赖、迁移完成和复习时间自动计算掌握状态，不提供手动“已掌握”勾选
- 将尚未订正的题目加入错题集，并记录审题、概念、建模、公式、运算、单位、方向和表达等错误原因
- 根据正式作答、提示、建模、自我解释、错题和迁移记录生成描述性学情分析
- 按证据化掌握状态查看知识点情况，并点击进入对应试题
- 提供改变条件、逆向设问和情境迁移三类举一反三练习，可保存推理记录
- 导入、导出 JSON 题库备份
- 导出、校验并事务恢复含附件和视频的 `.pslab` 完整备份
- 管理学生、试卷成绩、教师观察和成长档案，导出描述性学情报告
- 按薄弱证据推荐同类题，并每日生成默认 5 道、最多 8 道课后测试
- 解析 DOCX、PDF、旧版 Word 与扫描图片为待审核候选题
- 通过受控服务端调用 ChatGPT 生成结构化分步解答和物理一致性校验
- 长沙物理互联网题源入口与定向搜索
- 按教材册、章、节浏览和筛选试题
- 长沙互联网题源及授权状态索引
- 授权题库批量导入模板
- 适配电脑、平板和手机屏幕
- 答案＋理由＋置信度的前概念诊断与误概念画像
- 苏格拉底式建模表、五级提示和提示依赖度记录
- 选择/数值题的离线规则反馈与九项透明校验状态
- 三类同步仿真、建模能力雷达图和间隔复习队列
- 公式、量纲、单位、矢量、数据拟合和图示草稿工具
- 教师本地组卷、内容审核、学生档案导入与班级薄弱点汇总
- 手机传感器实验、CSV 导出和不确定度记录
